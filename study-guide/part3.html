10. Theming with Twig

10.1 Meaning

A theme controls presentation: templates (Twig), styles (CSS), scripts (JS), and regions. Core themes in Drupal 11: Olivero (default front end), Claro (admin), Stark (bare, for learning), Starterkit (generator for new themes), Stable9 (stable markup base).

Interview one-liner: "Themes use the Twig template engine. A theme declares regions and asset libraries in YAML, overrides core markup by copying a template to the theme, and uses preprocess functions to prepare variables."

10.2 Create a custom theme from Starterkit (the Drupal 11 way)

ddev exec php core/scripts/drupal generate-theme my_theme --path themes/custom
# result: web/themes/custom/my_theme/
ddev drush theme:install my_theme -y
ddev drush config:set system.theme default my_theme -y
ddev drush cr

Starterkit copies a clean theme that does not depend on Olivero afterwards (it is "forked", no base-theme inheritance).

10.3 Theme file anatomy

web/themes/custom/my_theme/
  my_theme.info.yml        # name, type, base theme, regions, libraries
  my_theme.libraries.yml   # asset libraries (css/js)
  my_theme.theme           # preprocess functions (PHP)
  css/style.css
  js/app.js
  templates/               # twig overrides
    node--event--teaser.html.twig
    page.html.twig
  components/              # single directory components (SDC)
  logo.svg, screenshot.png

my_theme.info.yml

name: My Theme
type: theme
description: Custom theme for training
package: Custom
core_version_requirement: ^11
base theme: stable9        # or false to build everything yourself
libraries:
  - my_theme/global
regions:
  header: Header
  primary_menu: Primary menu
  content: Content
  sidebar: Sidebar
  footer: Footer

my_theme.libraries.yml

global:
  css:
    theme:
      css/style.css: {}
  js:
    js/app.js: {}
  dependencies:
    - core/drupal
    - core/once

Attach a library: globally via libraries: in info.yml; in Twig: {{ attach_library('my_theme/global') }}; in PHP render array: $build['#attached']['library'][] = 'my_theme/global';.

10.4 Twig syntax (memorise)

SyntaxMeaning / example
{{ var }}Print a variable (auto-escaped, safe).
{% if x %} ... {% endif %}Logic; also for, set, include, extends, block.
{# comment #}Comment.
{{ content.field_location }}Render a field with its formatter.
{{ content|without('field_image') }}Render everything except a field.
{{ label }}Node title.
{{ url }}Node URL.
{{ node.field_location.value }}Raw value of a field.
{{ 'Hello'|t }}Translate a string.
{{ path('entity.node.canonical', {'node': 1}) }}URL from route name.
{{ attributes.addClass('card') }}Add a CSS class.
{{ dump(var) }}Debug (with Twig debug on).
|rawOutput unescaped HTML. Avoid; XSS risk.
{% include '@my_theme/partials/card.html.twig' with {title: label} %}Include a partial.

10.5 Template suggestions and debugging

Drupal picks the most specific template name. Order for a teaser Event node:

node--event--teaser.html.twig
node--event.html.twig
node--teaser.html.twig
node.html.twig

Naming rules: double dash -- separates specificity levels; underscores in machine names turn into hyphens in file names.

Turn on Twig debug (dev only)

cp web/sites/default/default.services.yml web/sites/default/services.yml
# edit services.yml under twig.config:
#   debug: true
#   auto_reload: true
#   cache: false
ddev drush cr

View page source: HTML comments list "THEME DEBUG", "FILE NAME SUGGESTIONS" (the x marks the one in use), and "BEGIN OUTPUT from ...". Copy that core template into your theme's templates/ and edit it.

Disable these settings on production. Twig cache off makes the site slow.

10.6 Preprocess functions

// my_theme.theme
function my_theme_preprocess_node(array &$variables) {
  $node = $variables['node'];
  if ($node->bundle() === 'event') {
    $variables['is_featured'] = (bool) $node->get('field_featured')->value;
  }
}
function my_theme_preprocess_page(array &$variables) {
  $variables['year'] = date('Y');
}
function my_theme_theme_suggestions_page_alter(array &$suggestions, array $variables) {
  if ($node = \Drupal::routeMatch()->getParameter('node')) {
    $suggestions[] = 'page__' . $node->bundle();
  }
}

Hook naming: THEMENAME_preprocess_HOOK. Clear cache after adding a new function (hook discovery is cached).

10.7 Single Directory Components (SDC)

Meaning: A component bundles its Twig, CSS, JS, schema, and metadata in one folder. Stable since Drupal 10.3. Reusable and documented.

themes/custom/my_theme/components/card/
  card.component.yml
  card.twig
  card.css
  card.js        (optional)
# card.component.yml
$schema: https://git.drupalcode.org/project/drupal/-/raw/HEAD/core/assets/schemas/v1/metadata.schema.json
name: Card
status: stable
props:
  type: object
  properties:
    title: { type: string, title: Title }
slots:
  body: { title: Body }
{# card.twig #}
<article {{ attributes.addClass('card') }}>
  <h3>{{ title }}</h3>
  {% block body %}{{ body }}{% endblock %}
</article>

Use it in any template: {{ include('my_theme:card', {title: label}) }} or {% embed 'my_theme:card' with {title: label} %}{% block body %}...{% endblock %}{% endembed %}. CSS and JS are loaded automatically when the component is rendered.

10.8 Responsive images, breakpoints

  • my_theme.breakpoints.yml defines breakpoints; the Responsive Image module maps them to image styles (/admin/config/media/responsive-image-style) to produce srcset.
  • Lazy loading is enabled by default on images in core formatters (loading="lazy").

10.9 Sub-theme vs Starterkit vs base theme

  • Sub-theme: inherits templates/CSS from a base theme via base theme:. Updates to the base flow in.
  • Starterkit: a one-time generated copy. No inheritance; you own all the code.
  • Admin theme: used for admin pages; set at Appearance → Administration theme.

11.7 Form API

Form class extends FormBase (general) or ConfigFormBase (settings stored in config).

<?php
namespace Drupal\training\Form;

use Drupal\Core\Form\FormBase;
use Drupal\Core\Form\FormStateInterface;

class FeedbackForm extends FormBase {
  public function getFormId(): string { return 'training_feedback'; }

  public function buildForm(array $form, FormStateInterface $form_state): array {
    $form['name'] = ['#type' => 'textfield', '#title' => $this->t('Name'), '#required' => TRUE];
    $form['email'] = ['#type' => 'email', '#title' => $this->t('Email')];
    $form['msg'] = ['#type' => 'textarea', '#title' => $this->t('Message')];
    $form['actions']['#type'] = 'actions';
    $form['actions']['submit'] = ['#type' => 'submit', '#value' => $this->t('Send')];
    return $form;
  }

  public function validateForm(array &$form, FormStateInterface $form_state): void {
    if (strlen($form_state->getValue('msg')) < 10) {
      $form_state->setErrorByName('msg', $this->t('Message too short.'));
    }
  }

  public function submitForm(array &$form, FormStateInterface $form_state): void {
    $this->messenger()->addStatus($this->t('Thanks, @n!', ['@n' => $form_state->getValue('name')]));
    $form_state->setRedirect('<front>');
  }
}
# routing
training.feedback:
  path: '/feedback'
  defaults:
    _form: '\Drupal\training\Form\FeedbackForm'
    _title: 'Feedback'
  requirements:
    _permission: 'access content'

Form lifecycle: build → (user submits) → validate → submit. Common elements: textfield, textarea, email, number, select, radios, checkboxes, checkbox, date, datetime, entity_autocomplete, managed_file, hidden, markup, details, fieldset, container, submit. Security: Drupal adds a CSRF token (form_token) automatically.

Config (settings) form

class SettingsForm extends ConfigFormBase {
  protected function getEditableConfigNames() { return ['training.settings']; }
  public function getFormId() { return 'training_settings'; }
  public function buildForm(array $form, FormStateInterface $form_state) {
    $config = $this->config('training.settings');
    $form['greeting'] = ['#type' => 'textfield', '#title' => 'Greeting',
      '#default_value' => $config->get('greeting')];
    return parent::buildForm($form, $form_state);
  }
  public function submitForm(array &$form, FormStateInterface $form_state) {
    $this->config('training.settings')->set('greeting', $form_state->getValue('greeting'))->save();
    parent::submitForm($form, $form_state);
  }
}

Provide defaults in config/install/training.settings.yml and a schema in config/schema/training.schema.yml.

11.8 Render arrays

$build = [
  '#theme' => 'item_list',
  '#items' => ['One', 'Two'],
  '#cache' => ['tags' => ['node_list'], 'contexts' => ['user.permissions'], 'max-age' => 600],
  '#attached' => ['library' => ['my_theme/global']],
];
$link = ['#type' => 'link', '#title' => 'Go', '#url' => \Drupal\Core\Url::fromRoute('<front>')];
$table = ['#type' => 'table', '#header' => ['A','B'], '#rows' => [[1,2],[3,4]]];

Properties start with #. #markup is filtered (XSS-safe); #plain_text escapes everything; #theme uses a theme hook; #type uses a render element.

11.9 Translation and escaping

  • $this->t('Hello @name', ['@name' => $x]) — @ escapes, % escapes and emphasises, : is for URLs. Never concatenate user input into t() strings.
  • Use StringTranslationTrait in services.
